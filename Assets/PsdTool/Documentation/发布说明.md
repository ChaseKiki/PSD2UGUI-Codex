# 发布说明

版本：2026.10.30-preview.11

团队试用版，主入口：Tools → PSD 工具 → 打开工具。先阅读同目录《使用说明.md》。

发布内容仅包括 Editor（不含 Tests）、Runtime、Photoshop 脚本、Documentation 和 CodexSkill。

preview.11：新建 AI 虚拟组使用英文名称，随包 skill 增加命名要求，生成端对中文/非法名称按控件或角色生成稳定英文名称。ScrollRect 生成时使用 uGUI 原生布局计算滚动条占比，空内容或不足一屏时 Handle 铺满，超出一屏时按可视区/内容比例缩放；轨道背景优先决定活动范围，没有背景时按可视区补全长度。分组滑块视觉随 Handle 伸缩。

preview.10：修复子列表先判为待处理、父 Dropdown 后接管时的状态遗漏；子项跟随有效父方案收起，父方案失败或忽略时恢复提示。已由父方案处理的旧子项按钮不再重复应用。空恢复方案不显示覆盖入口，也不提交通用空计划校验；独立的完整覆盖方案仍保留来源、属性锁和归属校验。

preview.9：按钮根热区取正常底图、文字等视觉并集，移除最小尺寸扩张，保持视觉位置；控件校验通过独立的生成归属定位异常，继续逐控件容错。待处理项支持明确应用完整 AI 覆盖方案（不越过来源和硬锁）；Progress 可配置线性/径向填充、方向、起点及初始进度。

preview.8：支持 None 混合控件容器携带完整拆组/绑定方案，提供单条应用；统一滚动条插槽、轨道与 ScrollRect 方向。识别结果增加整体生成预检；可定位的控件构建/引用错误隔离为外观输出，保留源配置及其余控件，生成报告标记交互待处理，不再由单控件校验拖住整页保存。增量生成保持 GUID/FileID 保护；环境和来源损坏不伪装成功。

preview.7：识别结果按待办、常规已选、历史折叠展示；每项增加真实 PSD 区域缩略图、放大与整图定位、源图层框选。人工处理按钮靠右并适配窄窗口；生成操作与结果独立分区，显示实际所选及异常数量。统一主工具、Codex 进度、资源、迁移、变更及配置面板，日常入口收敛为解析、识别、生成。图片仅用于本地查看，不额外调用 AI。

preview.6：区域异常改为局部隔离。“非控件 + 结构修改”、缺项/重复、未知部件和单控件校验失败不再拒绝整份可用结果。无效父方案不会提前占用子区域；应用阶段逐控件事务继续执行有效项并合并 Undo。异常保留报告，支持定位、人工指定类型重校验、人工配置更新校验及不重新请求 AI 的历史结果重读。任务身份/过期/篡改/JSON 损坏和环境故障仍保留整体保护，不自动越过审核。

preview.5：基于 preview.4 依次接入 P0。全部区域结果保留并区分状态；Codex 读取来源图层表和编号缩略图，输出部件/虚拟组/换父级建议；图标/无字/双字/多背景按钮、包装组、InputField/Dropdown 结构及线性 Slider/Progress 绑定接入。环形 Progress 明确显示不支持。原人工/锁定/透明度保护扩展至隐藏、剪贴、遮罩和组效果继承。

新项目持久状态转入 Editor/Data，运行 TMP 材质单独输出；缓存单独标识。旧项目通过资源管理中的迁移清单确认后保留 GUID 移动，不自动改已有项目。构建预检阻止编辑登记数据进入 Resources。安装包明确排除 Editor/Data 和 Runtime/Generated。

本轮真实 Codex 错组夹具恢复了输入框提示文字归属；常见控件/虚拟组/锁定继承与 GUID 迁移检查、Windows 最小 Player 实际构建和运行检查通过。已有资源/增量/控件交互回归通过。Windows Player 验收不等于 Android/iOS 真机验收；模型案例不代表多稿准确率。

preview.4：菜单仅保留“打开工具”和“资源管理”。移除独立 AI 配置窗口、本地/API 识别和识别方式选择；旧后端设置仅作隐藏序列化兼容。重建索引与待删除审核收进“维护与审核”，保留资源管理和增量保护。首次安装检测、ChatGPT 登录在识别窗口完成，新电脑体验入口收进高级，不再出现“PSD 工具辅助”菜单。

升级请覆盖导入包中全部工具文件。旧 AiSetupWindow.cs 以原 GUID 的无窗口占位源码覆盖，防止 unitypackage 追加导入残留旧菜单；不包含旧窗口实现。旧配置/节点树/业务输出不随包发布，也无需删除。

不包含当前配置资产、Data、项目 UI/字体/PSD、测试代码或资产、Library、AI 模型和本机设置。默认配置在首次打开工具时创建。`PsdTool.Runtime` 中的运行时组件是生成 Prefab 的依赖，请随项目保留。

前置依赖：uGUI、TextMeshPro 与 TMP 基础资源；默认 AI 流程使用官方 Codex 加任务自带 skill，不再要求 Ollama、本地模型或单独的 API。图片 FX 另需 Photoshop。外部程序不捆绑在本包中。

新增：点击 Codex 识别后，Unity 自动调用已登录 ChatGPT 的官方 Codex CLI，以只读图片和结构化回答完成识别，自动打开结果勾选列表。无需复制指令、手动回传或本地模型；首次安装与登录由程序同学协助。登录由官方客户端管理，工具不读取凭据、不代理账号、不继承 API Key。

识别界面默认仅保留状态、取消/重试和结果入口；目录、手动交接等排错操作收进高级。结果列表默认只显示控件、说明和勾选框，绑定明细默认收起。增加取消与 15 分钟总超时。确认前不修改节点树或 Prefab，原有完整性/过期/任务隔离校验继续生效。手动 Codex 文件交接仍保留在高级选项中。

空工程联调修正：首次推荐上下文改为 4096，减少与 Unity 同时运行的显存压力；修复半透明分组缺失 CanvasGroup 时的 Unity 假空对象判空问题。

本版文件流程验收：真实 PSD 导出 11 个区域，使用者在官方 Codex 完成回传，Unity 自动预览、7 个完整计划确认生成、来源绑定与增量保留通过；错误任务/旧稿/半写入等拒绝路径另有测试。模拟分类测试与真实 Codex 回传分开记录，详见发布目录验证记录。

当前 PSD 已完成移除规则命名/标记的区域识别与引用验收，以及真实生成 Prefab 的交互测试；另一个中文普通命名 PSD 已获使用者反馈大部分正确。没有多稿准确率统计，也没有 PSD2UGUI_X Pro 的同稿对照测试。

空工程包导入验证结果随发布目录的验证记录提供，避免将“同机空工程可用”理解为所有版本、所有机器都已验证。
